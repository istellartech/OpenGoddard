13. 極座標・2段軌道投入
==================================================

極座標で2段ロケットの軌道投入と区間接続を扱います。

実行方法
--------

リポジトリのルートから実行します。

.. code-block:: console

   uv run python examples/13_rocket_ascent_polar_tsto/main.py

物理パラメータや初期推定は ``main.py`` に記述しています。
求解後にMatplotlibで図を表示します。図を保存する設定の例では、このフォルダ内の
``output/`` に保存します。

ファイル構成
------------

* ``main.py``：この例題の実装と実行入口。
* ``README.rst``：この例題の説明と実行方法。
* ``figures/``：以前から同梱されている参考図。今回の実行結果ではありません。
* ``output/``：生成した図・動画・JSONなどの保存先。必要時に作成し、Git管理対象外とします。

`全例題の一覧と共通の使い方 <../README.rst>`_
