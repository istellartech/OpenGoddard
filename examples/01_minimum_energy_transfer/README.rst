01. 最小操作量の移動
==================================================

状態1個の移動から、終端時間と積分目的関数を学びます。解析解との比較を含みます。

実行方法
--------

リポジトリのルートから実行します。

.. code-block:: console

   uv run python examples/01_minimum_energy_transfer/main.py

図は表示せず、計算値と解析解を比較して終了します。
パラメータや初期推定は ``main.py`` に記述しています。

ファイル構成
------------

* ``README.rst``：この例題の説明と実行方法。
* ``output/``：生成した図・動画・JSONなどの保存先。必要時に作成し、Git管理対象外とします。
