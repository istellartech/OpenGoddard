## Running the examples

Run from the repository root after [installing the environment](../#installation):

```sh
uv run python examples/07_goddard_0knot.py
```

Change the values in each script's `PARAMETERS` dictionary or `Rocket` class to solve with different conditions.
The scripts retain their original Japanese comments; these pages explain the models in English.
