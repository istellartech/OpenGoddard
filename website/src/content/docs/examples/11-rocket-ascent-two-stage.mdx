[10. 単段ロケット上昇](../10-rocket-ascent-single-stage/) と同じ鉛直上昇モデルに、**段分離**を加えます。
1段目の構造を切り離すと、ロケットの質量は一瞬で減りますが、位置と速度は変わりません。
この「一部の状態だけが不連続になる」境界を、phase の knot と接続条件で表します。

## この例題で学ぶこと

- 段分離を phase の境界（knot）として表す方法
- `knot_states_smooth = [False]` で自動の連続条件を外し、接続条件を自分で書く方法
- 質量のジャンプ、位置・速度の連続を等式制約で書き分けること
- 段分離時刻を最適化変数として扱い、その下限を与える方法

## 問題設定

状態・制御・運動方程式は 10 と同じで、両方の phase に同じ式を使います。

$$
\dot{R} = v, \qquad
\dot{v} = \frac{T - \tfrac{1}{2}\rho(R) v^2 C_D A}{m} - \frac{\mu}{R^2}, \qquad
\dot{m} = -\frac{T}{g_0 I_{sp}}, \qquad
\rho = 1.225\, e^{-(R - R_e)/8500}
$$

パラメータも 10 と同じ（$m_0 = 5000$ kg, $C_D = 0.2$, $A = 10$ m², $I_{sp} = 300$ s,
$T_{\max} = 2 m_0 g_0 \approx 98.07$ kN）で、`Rocket` には段ごとの質量 `M0_1st = 3000`, `M0_2nd = 2000` が加わります。
最大推力は両段で共通です。

時間を段分離時刻 $t_s$ で2つに分けます。

$$
\text{phase 0（1段目）}: [0, t_s], \qquad \text{phase 1（2段目）}: [t_s, t_f]
$$

境界条件は、地表で静止状態から出発し、2段目の推進剤を使い切って最高点で速度0になることです。

$$
R(0) = R_e, \quad v(0) = 0, \quad m(0) = 5000, \qquad v(t_f) = 0, \quad m(t_f) = 0.4 \times 2000 = 800\ \text{kg}
$$

段分離（knot）での**接続条件**は次のとおりです。位置と速度は連続、質量は 1200 kg だけ減ります。

$$
R(t_s^-) = R(t_s^+), \qquad v(t_s^-) = v(t_s^+), \qquad m(t_s^-) = m(t_s^+) + 1200
$$

変数の範囲は $R \ge R_e$, $v \ge 0$, $800 \le m \le 5000$, $0 \le T \le T_{\max}$,
$t_s \ge 50$ s, $t_f \ge 50$ s です。目的関数は 10 と同じく $J = -R(t_f)/R_e$ です。

1200 kg は `M0_1st * Mc`（$3000 \times 0.4$）に等しく、1段目の構造質量に相当すると読めますが、
コードでは定数として直接書かれています。また、各段に積む推進剤量を制約する条件はありません。
このモデルでの段分離は「いつ切り離しても 1200 kg を捨てる」操作で、1段目に残った推進剤は
2段目の質量としてそのまま持ち越されます。

## 数式とコードの対応

| 数式 | コード（`main.py`） |
| --- | --- |
| 2つの phase、初期の分離時刻 300 s | `time_init = [0.0, 300, 600]`, `n = [25, 25]` |
| 両 phase で同じ運動方程式 | `prob.dynamics = [dynamics, dynamics]` |
| 自動の状態連続を外す | `prob.knot_states_smooth = [False]` |
| $R(t_s^-)=R(t_s^+)$ | `result.equal(R1[-1], R2[0])`（`R1 = prob.states(0, 0)`, `R2 = prob.states(0, 1)`） |
| $v(t_s^-)=v(t_s^+)$ | `result.equal(v1[-1], v2[0])` |
| $m(t_s^-)=m(t_s^+)+1200$ | `result.equal(m1[-1], m2[0] + 1200)` |
| 初期条件・終端条件 | `result.equal(R[0], obj.Re)` ほか、`result.equal(m[-1], obj.M0_2nd * obj.Mc)` |
| $800 \le m \le 5000$ | `prob.set_states_bounds_all_section(2, obj.M0_2nd * obj.Mc, obj.M0)` |
| $t_s \ge 50,\ t_f \ge 50$ | `prob.set_time_final_bounds(0, 50.0, None)`, `prob.set_time_final_bounds(1, 50.0, None)` |
| $J=-R(t_f)/R_e$ | `cost` が `-R[-1] / obj.Re` を返す |

`knot_states_smooth = [True]` にすると、ライブラリが knot で**全状態**（$R, v, m$）の連続を自動で課します。
それでは質量のジャンプが表せないので、ここでは `False` にして自動の条件を外し、
`equality` の中で「knotting condition」として3本の等式を自分で書いています。
制御 $T$ にはもともと連続条件がないので、分離の前後で推力は自由に変われます。
分離時刻 $t_s$ は phase 0 の終端時刻 `prob.time_final(0)` そのもので、最適化変数です。

## 計算結果

左は鉛直に上昇するロケット（▲、縦軸は高度 km）と、相対的な推力の大きさを表すオレンジの炎、
右は速度・質量・推力の時間履歴です。縦の点線が段分離（knot）、黒い縦線が動画の現在時刻です。

### 読み取りのポイント

- 質量のグラフは、点線の位置で約 3834 kg から約 2634 kg へ**垂直に 1200 kg 落ちます**。
  これが `m1[-1] = m2[0] + 1200` の結果です。速度のグラフは点線でつながっていて、位置・速度の連続条件が効いています。
- 分離時刻は下限の $t_s = 50$ s に張り付いています。このモデルでは1段目の推進剤を2段目に持ち越せるので、
  不要な 1200 kg をできるだけ早く捨てるのが有利だからです。そのため1段目は推進剤を約 1166 kg しか使いません。
- 分離の直前に推力がほぼ0になり、速度が一度下がっています。分離直後は再び最大推力から始まり、
  その後は 40〜60 kN 程度の中間推力で、約 170 秒で質量が 800 kg に達して推進剤が尽きます。
- 以降は慣性上昇で、速度は最大約 1.58 km/s から直線的に減り、約 339 秒で 0 になります。
  到達高度は約 217 km で、同じ初期質量の 10（約 65 km）より大幅に高くなります。
  ただし、両者は終端質量の条件（10 は 2000 kg、こちらは 800 kg）も異なる点に注意してください。

## 試してみる

<RunCommand id="rocket_ascent_two_stage" />

`main.py` を次のように書き換えて違いを観察してみましょう。

- `prob.set_time_final_bounds(0, 50.0, None)` の下限 `50.0` を `100.0` などに変えると、分離時刻はその下限に移るでしょうか。
  到達高度はどれだけ下がるでしょうか。
- `m2[0] + 1200` の 1200 を小さく（構造を軽く）すると、到達高度はどう変わるでしょうか。
- 1段目の推進剤量を固定したい場合は、例えば `result.equal(m1[-1], 3800)` のような等式を追加します。
  分離時刻と推力履歴がどう変わるかを比べてみましょう。
- `prob.knot_states_smooth = [True]` にすると、自動の質量連続と手書きの「1200 kg 減る」条件が矛盾します。
  ソルバーがどう振る舞うかを確かめてみましょう。
