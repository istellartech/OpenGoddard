[10. 単段ロケット上昇](../10-rocket-ascent-single-stage/) の鉛直上昇モデルに段分離を加えます。
分離の瞬間、質量は一気に減りますが、位置と速度は変わりません。この「一部の状態だけが跳ぶ」境界を、
phase の境界（knot）での接続条件として書きます。

## 問題

状態は地心距離 $R$、速度 $v$、質量 $m$、制御は推力 $T$ です。運動方程式は10と同じで、両方の phase に使います。

$$
\dot{R} = v,\quad
\dot{v} = \frac{T - \tfrac12 \rho(R) v^2 C_D A}{m} - \frac{\mu}{R^2},\quad
\dot{m} = -\frac{T}{g_0 I_{sp}},\qquad
\rho = 1.225\,e^{-(R-R_e)/8500}
$$

phase 0（1段目）を $[0, t_s]$、phase 1（2段目）を $[t_s, t_f]$ とし、分離時刻 $t_s$ も最適化変数です。

$$
\begin{aligned}
&R(0)=R_e,\ v(0)=0,\ m(0)=5000,\qquad v(t_f)=0,\ m(t_f)=800, \\
&R(t_s^-)=R(t_s^+),\quad v(t_s^-)=v(t_s^+),\quad m(t_s^-)=m(t_s^+)+1200, \\
&0 \le T \le 2 m_0 g_0,\quad 800 \le m \le 5000,\quad t_s,\ t_f \ge 50\ \mathrm{s},\qquad
J = -R(t_f)/R_e
\end{aligned}
$$

1200 kg は1段目の構造質量（$3000 \times 0.4$）に当たる定数です。各段の推進剤量は制約していないので、
1段目に残った推進剤はそのまま2段目へ持ち越されます。

## コードとの対応

| 数式 | `main.py` |
| --- | --- |
| 2つの phase | `time_init = [0.0, 300, 600]`、`n = [25, 25]`、`prob.dynamics = [dynamics, dynamics]` |
| knot での自動連続を外す | `prob.knot_states_smooth = [False]` |
| 位置・速度の連続 | `result.equal(R1[-1], R2[0])`、`result.equal(v1[-1], v2[0])` |
| 質量のジャンプ | `result.equal(m1[-1], m2[0] + 1200)` |
| 終端条件 | `result.equal(v[-1], 0.0)`、`result.equal(m[-1], obj.M0_2nd * obj.Mc)` |
| 状態・制御・時刻の範囲 | `set_states_bounds_all_section`、`set_controls_bounds_all_section`、`set_time_final_bounds(0, 50.0, None)` |
| $J=-R(t_f)/R_e$ | `cost` が `-R[-1] / obj.Re` を返す |

`knot_states_smooth = [True]` だと、ライブラリが knot で $R, v, m$ すべての連続を課すので質量のジャンプが表せません。
`R1 = prob.states(0, 0)` が phase 0、`R2 = prob.states(0, 1)` が phase 1 の値で、`[-1]` と `[0]` が境界のノードです。
推力にはもともと連続条件がないので、分離の前後で自由に変われます。
求解は1回の長い SLSQP 実行（`ftol=1e-10, maxiter=2000`）です。

## 結果

質量のグラフの段差と、そこで高度・速度がつながっていることを確認してください。

<ExampleMedia id="rocket_ascent_two_stage" />

- 質量は分離時刻で約 3835 kg から約 2635 kg へ、ちょうど 1200 kg 垂直に落ちます。高度と速度は連続です。
- 分離時刻は下限の $t_s = 50$ s に張り付きます。推進剤を持ち越せるので、不要な 1200 kg は早く捨てるほど有利です。
- 1段目は分離前に推力をほぼ 0 まで絞り、2段目は最大推力から燃焼を始めます。
- 推進剤が尽きた後は慣性上昇し、到達高度は約 217 km です（10 とは終端質量の条件も違います）。
