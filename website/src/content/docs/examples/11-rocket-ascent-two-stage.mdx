[10. 単段ロケット上昇](../10-rocket-ascent-single-stage/) の鉛直上昇に段分離を加える。段分離では位置と速度が連続のまま質量だけが不連続に減る。これを phase 境界（knot）の接続条件として書く。

## 問題

状態 $(R, v, m)$、制御 $T$。両 phase で10と同じ運動方程式を使う。

$$
\dot{R} = v,\quad
\dot{v} = \frac{T - \tfrac12 \rho(R) v^2 C_D A}{m} - \frac{\mu}{R^2},\quad
\dot{m} = -\frac{T}{g_0 I_{sp}},\qquad
\rho = 1.225\,e^{-(R-R_e)/8500}
$$

phase 0 を $[0, t_s]$、phase 1 を $[t_s, t_f]$ とし、$t_s$ も最適化する。1200 kg は1段目の構造質量である。

$$
\begin{aligned}
&R(0)=R_e,\ v(0)=0,\ m(0)=5000,\qquad v(t_f)=0,\ m(t_f)=800, \\
&R(t_s^-)=R(t_s^+),\quad v(t_s^-)=v(t_s^+),\quad m(t_s^-)=m(t_s^+)+1200, \\
&0 \le T \le 2 m_0 g_0,\quad 800 \le m \le 5000,\quad t_s,\ t_f \ge 50\ \mathrm{s},\qquad
J = -R(t_f)/R_e
\end{aligned}
$$

## コードとの対応

| 数式 | `main.py` |
| --- | --- |
| 2つの phase | `time_init = [0.0, 300, 600]`、`n = [25, 25]`、`prob.dynamics = [dynamics, dynamics]` |
| knot での自動連続を外す | `prob.knot_states_smooth = [False]` |
| 位置・速度の連続 | `result.equal(R1[-1], R2[0])`、`result.equal(v1[-1], v2[0])` |
| 質量のジャンプ | `result.equal(m1[-1], m2[0] + 1200)` |
| $J$ | `cost` が `-R[-1] / obj.Re` を返す |

`knot_states_smooth = [True]` では全状態の連続が課され、質量ジャンプを表せない。求解は `ftol=1e-10, maxiter=2000` の1回の SLSQP 実行である。

## 結果

分離時刻で質量だけが 1200 kg 落ち、高度と速度は連続になる。

<ExampleMedia id="rocket_ascent_two_stage" />

- 分離時刻は下限 $t_s = 50$ s に張り付く。推進剤を2段目へ持ち越せるので、構造質量は早く捨てるほど有利である。
- 1段目は分離前に推力をほぼ 0 まで絞り、2段目は最大推力から燃焼する。推進剤が尽きた後は慣性上昇し、到達高度は約 217 km である。
