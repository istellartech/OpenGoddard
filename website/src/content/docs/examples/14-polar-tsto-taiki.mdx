[13](../13-rocket-ascent-polar-tsto/) の2段ロケットに実データの大気・抗力係数と外気圧による推力・比推力補正を加える。北海道大樹町から軌道傾斜角 96.7° で打ち上げ、高度 561 km の円軌道へ投入する。

## 問題

状態・制御・運動方程式の形は13と同じで、抗力と比推力の中身が異なる。

`data/US_standard_atmosphere.csv`（0〜86 km）から $P(h)$、$\rho(h)$、音速 $a(h)$ を線形補間する。86 km より上では抗力は 0 になる。`data/Cd.csv` から $C_d(M)$ を補間する（範囲外は外挿）。

$$
M = \frac{\lvert V\rvert}{a(h)},\qquad D_{r,t} = \tfrac12 \rho(h)\, V_{r,t} \lvert V\rvert\, C_d(M)\, A
$$

ノズル出口面積 $A_{e,i}$ に働く外気圧の差を推力増分 $\Delta T_i$ とし、基準質量流量 $\dot{m}_{\mathrm{ref},i} = T_{\max,i}/(I_{sp,i} g_0)$ で比推力に換算する。1段目の基準は海面値、2段目は真空値である。

$$
\Delta T_1 = \bigl(P(H_0) - P(h)\bigr) A_{e,1},\quad \Delta T_2 = P(h) A_{e,2},\qquad
I_{sp,i}(h) = I_{sp,i} + \frac{\Delta T_i}{\dot{m}_{\mathrm{ref},i}\, g_0},\qquad
\dot{m} = -\frac{\sqrt{T_r^2+T_t^2}}{g_0 I_{sp,i}(h)}
$$

初期周方向速度 $V_0 = V_{\mathrm{taiki}} \cos(-96.7^\circ)$ は地球自転の軌道面内成分である。各段の初期質量は乾燥質量（1300 kg、220 kg）と構造効率から決め、2段目にペイロード 100 kg を加える。

$$
\begin{aligned}
&R(0)=R_e+10\,\mathrm{m},\ \theta(0)=V_r(0)=0,\ V_t(0)=V_0,\ m(0)=M_{0,1}+M_{0,2};\qquad
R(t_f)=R_e+561\,\mathrm{km},\ V_r(t_f)=0,\ V_t(t_f)=\sqrt{GM_e/R(t_f)} \\
&(R,\theta,V_r,V_t)(t_s^+) = (R,\theta,V_r,V_t)(t_s^-),\qquad m(t_s^+) = M_{0,2} \\
&\sqrt{T_r^2+T_t^2} \le T_{\max,i} + \Delta T_i,\quad q \le 500\,\mathrm{kPa},\quad \lvert \boldsymbol{T}-\boldsymbol{D}\rvert/m \le 20 g_0,\quad
m \ge M_{\mathrm{dry},1} + M_{0,2}\ (\text{1段目}),\quad m \ge 220\ (\text{2段目}),\qquad J = -m(t_f)/M_{0,1}
\end{aligned}
$$

## コードとの対応

| 数式 | `main.py` |
| --- | --- |
| 標準大気の補間 | `airDensity = interpolate.interp1d(stdAltitude, stdDensity, ...)`（`airPressure`、`airSound` も同様） |
| $C_d(M)$ | `Cd = interpolate.interp1d(CdLog[:, 0], CdLog[:, 1], fill_value="extrapolate")` |
| $\Delta T_i$ | `dThrust = [(obj.airPressure(obj.H0) - obj.airPressure(R - obj.Re)) * obj.Ae[0], obj.airPressure(R - obj.Re) * obj.Ae[1]]` |
| $I_{sp,i}(h)$ | `Isp = obj.Isp[section] + dThrust[section] / (obj.refMdot[section] * g0)` |
| 推力上限 | `result.upper_bound(T0, obj.ThrustMax[0] + dThrust0, ...)`（`T1` も同様） |
| $V_0$ | `self.V0 = self.Vt_taiki * np.cos(-self.inclination * np.pi / 180.0)` |

CSV はクラス定義内で一度だけ読み込む。求解は13と同じく `ftol=1e-6, maxiter=3000` の1回の SLSQP 実行で、数分かかる。

## 結果

飛行の流れは13と同じで、1段目の推力が高度とともに基準値を超える。

<ExampleMedia id="polar_tsto_taiki" />

- 傾斜角が 90° を超えるため、$V_t(0)$ は約 −40 m/s と負になる。外気圧の低下で上限 $T_{\max,1} + \Delta T_1$ が増え、1段目の推力は基準の最大推力を超える。
- 最終質量は約 343 kg である。表示される `payload` は最終質量から2段目乾燥質量 220 kg を引いた値である。
- 最終質量は慣性飛行の長さにほとんど依存しないため、慣性飛行の長さと $t_f$ は計算環境によって変わる。
