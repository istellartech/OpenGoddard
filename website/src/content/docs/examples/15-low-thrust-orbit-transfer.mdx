重力の 1% 以下の推力で、半径 1 の円軌道から半径 4 の円軌道へ遷移する。要点は L1 型目的関数の滑らかな書き換えと、収束のための初期推定・制約の与え方である。

## 問題

重力定数と初期半径を 1 とする無次元量を使う。状態は $(r, v_r, v_t)$、制御は推力加速度の各成分を非負の2変数に分けた $u_{r1}, u_{r2}, u_{t1}, u_{t2}$ である。

$$
\dot{r} = v_r,\quad
\dot{v}_r = \frac{v_t^2}{r} - \frac{1}{r^2} + (u_{r1}-u_{r2}),\quad
\dot{v}_t = -\frac{v_r v_t}{r} + (u_{t1}-u_{t2})
$$

$$
\begin{aligned}
&r(0)=1,\ v_r(0)=0,\ v_t(0)=1;\qquad r(t_f)=4,\ v_r(t_f)=0,\ v_t(t_f)=0.5 \\
&0 \le u_{r1}, u_{r2}, u_{t1}, u_{t2} \le 0.01,\quad 1 \le r \le 4,\quad 1 \le t_f \le 55,\qquad
J = \int_0^{t_f} (u_{r1}+u_{r2}+u_{t1}+u_{t2})\,dt
\end{aligned}
$$

$\lvert u_r\rvert$ は 0 で微分できないため、$u_r = u_{r1} - u_{r2}$ と非負の2変数に分けて和を最小化する。最適解では片方が 0 になり、和は $\lvert u_r\rvert$ に一致する（$u_t$ も同様）。右辺に $\theta$ は現れないので状態に含めず、描画時に $\dot{\theta} = v_t/r$ を積分して復元する。

## 手で書く順序

終端コストから積分コストへ戻る。正負それぞれの非負の推力変数を作り、運動方程式では差、燃料使用量では和を使う理由を確かめる。

## コードとの対応

| 数式 | 例題のPythonファイル |
| --- | --- |
| 運動方程式 | `dx[1] = vt**2 / r - 1 / r**2 + (ur1 - ur2)`、`dx[2] = -vr * vt / r + (ut1 - ut2)` |
| $1 \le r \le 4$ | `result.lower_bound(r[1:-1], p["r0"])`、`result.upper_bound(r[1:-1], p["rf"])` |
| 制御と $t_f$ の範囲 | `problem.set_controls_bounds(control, 0, 0.0, p["u_max"])`、`problem.set_time_final_bounds(0, 1.0, p["tf_max"])` |
| $J$ | `running_cost` が `(ur1 + ur2) + (ut1 + ut2)` を返す |
| 初期推定 | `time_init = [0.0, 50.0]`、`vt_init = 1 / np.sqrt(r_init)` |

収束には次の2点が必要である。
- **実行可能に近い初期推定。** 遷移には $t_f \approx 35$ 以上かかる。$t_f = 10$ から始めると SLSQP は最初の反復で `Inequality constraints incompatible` になる。$t_f = 50$ から始め、$v_t$ を各半径の円軌道速度 $1/\sqrt{r}$ とする。
- **制約を重複させない。** 端点の $r$ は `equality` で固定済みなので、範囲制約は内部ノード `r[1:-1]` だけに課す。制御と $t_f$ の範囲は不等式制約ではなく box bounds で与える。重複した制約は部分問題を退化させる。

## 結果

軌道は渦巻き状に広がり、各制御は L1 型目的関数の特徴として上限か 0 をとる。

<ExampleMedia id="low_thrust_orbit_transfer" />

- $t_f$ は上限 55 に張り付き、$J \approx 0.579$ となる。推力の大部分は周方向で、$u_t$ はほぼ全区間で上限 0.01 である。
- 終盤に $u_r$ で外向きに押し出し、短い慣性飛行の後、内向きの $u_r$ で $v_r$ を 0 に戻して円軌道に入る。
