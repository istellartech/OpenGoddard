電気推進のような小さな推力で、半径 1 の円軌道から半径 4 の円軌道へ移ります。推力は重力の 1% しかないので、
中心天体の周りを回りながら少しずつ軌道を広げます。絶対値の目的関数を滑らかな形に書き換える方法と、
収束させるための初期推定・制約の書き方がこの例題の要点です。

## 問題

重力定数と初期半径を 1 とする無次元量で考えます。状態は $(r, v_r, v_t)$、制御は推力加速度の各成分を
非負の2変数に分けた $u_{r1}, u_{r2}, u_{t1}, u_{t2}$ です。

$$
\dot{r} = v_r,\quad
\dot{v}_r = \frac{v_t^2}{r} - \frac{1}{r^2} + (u_{r1}-u_{r2}),\quad
\dot{v}_t = -\frac{v_r v_t}{r} + (u_{t1}-u_{t2})
$$

$$
\begin{aligned}
&r(0)=1,\ v_r(0)=0,\ v_t(0)=1;\qquad r(t_f)=4,\ v_r(t_f)=0,\ v_t(t_f)=0.5 \\
&0 \le u_{r1}, u_{r2}, u_{t1}, u_{t2} \le 0.01,\quad 1 \le r \le 4,\quad 1 \le t_f \le 55,\qquad
J = \int_0^{t_f} (u_{r1}+u_{r2}+u_{t1}+u_{t2})\,dt
\end{aligned}
$$

推進剤の消費は $\int(\lvert u_r\rvert + \lvert u_t\rvert)\,dt$ ですが、$\lvert u\rvert$ は 0 で微分できません。
$u_r = u_{r1} - u_{r2}$（ともに非負）と分けて和を最小化すると、最適解では片方が 0 になり、和が $\lvert u_r\rvert$ に一致します。
右辺に $\theta$ は現れないので状態から外し、描画のときだけ $\dot{\theta} = v_t/r$ を積分して復元します。

## コードとの対応

| 数式 | `main.py` |
| --- | --- |
| 運動方程式 | `dx[1] = vt**2 / r - 1 / r**2 + (ur1 - ur2)`、`dx[2] = -vr * vt / r + (ut1 - ut2)` |
| 円軌道から円軌道へ | `equality` の `result.equal(r[0], obj.r0)` 〜 `result.equal(vt[-1], obj.vtf)` |
| $1 \le r \le 4$ | `result.lower_bound(r[1:-1], obj.r0)`、`result.upper_bound(r[1:-1], obj.rf)` |
| 制御と $t_f$ の範囲 | `prob.set_controls_bounds(control, 0, 0.0, obj.u_max)`、`prob.set_time_final_bounds(0, 1.0, obj.tf_max)` |
| $J$ | `running_cost` が `(ur1 + ur2) + (ut1 + ut2)` を返す |
| 初期推定 | `time_init = [0.0, 50.0]`、`vt_init = 1 / np.sqrt(r_init)` |
| $\theta$ の復元 | `integrate.cumulative_trapezoid(vt / r, time, initial=0)` |

収束には2つの工夫が必要でした。

- **実行可能に近い初期推定。** 推力が小さいので遷移には少なくとも $t_f \approx 35$ かかります。以前の $t_f = 10$ からでは
  SLSQP が最初の反復で `Inequality constraints incompatible` になりました。$t_f \approx 50$ から始め、$v_t$ を各半径の円軌道速度 $1/\sqrt{r}$ にしています。
- **制約を重複させない。** 端点の $r$ は `equality` で固定済みなので、範囲制約は内部のノード `r[1:-1]` だけに課します。
  制御と $t_f$ の範囲は不等式ではなく `set_controls_bounds`・`set_time_final_bounds` の上下限（box bounds）で与えます。
  重複した制約は部分問題を退化させ、環境によって失敗していました。

## 結果

渦巻き状に広がる軌道と、制御が上限か 0 に張り付く様子を見てください。

<ExampleMedia id="low_thrust_orbit_transfer" />

- 終端時刻は上限の $t_f = 55$ に張り付き、$J \approx 0.579$ です。時間をかけるほど推進剤は少なくて済みます。
- 軌道は約 3.8 周しながら半径 1 から 4 へ広がります。
- 推力の大部分は周方向で、$u_t$ はほぼ全区間で上限 0.01 です。軌道が広がるにつれて $v_t$ は下がります。
- 終盤に $u_r$ を上限まで使って外へ押し出し、短い慣性飛行の後、$u_r = -0.01$ で $v_r$ を 0 に戻して円軌道に入ります。
- 制御が上限か 0 のどちらかを取るのは、L1 型の目的関数の特徴です。
