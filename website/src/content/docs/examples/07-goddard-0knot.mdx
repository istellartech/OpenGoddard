鉛直に上昇するロケットが、決まった推進剤量で到達高度を最大にする推力履歴を求める（Goddard問題）。全区間を1つの phase で解き、[08](../08-goddard-1knot/) と比較する基準とする。

## 問題

無次元量で、状態は高度 $h$・速度 $v$・質量 $m$、制御は推力 $T$。終端時刻 $t_f$ は自由。

$$
\dot{h} = v,\quad \dot{v} = \frac{T - D_c v^2 e^{-H_c (h-h_0)/h_0}}{m} - g_0\left(\frac{h_0}{h}\right)^2,\quad \dot{m} = -\frac{T}{c}
$$

$$
h(0)=1,\ v(0)=0,\ m(0)=1,\qquad v(t_f)=0,\ m(t_f)=0.6,\qquad
0 \le T \le T_{\max},\quad J = -h(t_f)
$$

$g_0=h_0=m_0=1$、$H_c=500$、$D_c=310$、$c=0.5$、$T_{\max}=3.5$。経路制約 $h \ge h_0$、$v \ge 0$、$0.6 \le m \le 1$、$t_f \ge 0.1$ を課す。

## コードとの対応

| 数式 | `main.py` |
| --- | --- |
| 運動方程式 | `xp.stack((v, (thrust - drag) / mass - gravity, -thrust / obj.c))` |
| 抗力・重力 | `drag = obj.Dc * v**2 * xp.exp(...)`、`gravity = obj.g0 * (obj.H0 / h) ** 2` |
| 境界条件 | `equality` の `result.equal(...)` 5本 |
| 経路制約 | `lower_bound(h[1:], obj.H0)`、`upper_bound(T, obj.T_max)` など |
| $J=-h(t_f)$ | `cost` が `-h[-1]` を返す |
| 1つの phase | `n = [50]`、`knot_states_smooth = []` |

## 結果

軌道と推力・速度・質量の時間履歴を示す。

<ExampleMedia id="goddard_0knot" />

- 推力は最大推力 → 中間推力（特異弧）→ 推力ゼロの順に変わる。特異弧では抗力を抑えるため速度を上げすぎない。
- 推進剤は $t \approx 0.077$ で尽き、最高高度は $h(t_f) \approx 1.0128$。
- 推力は推力ゼロへの切り替え前後で振動する。50ノードの1本の多項式で不連続な推力を近似するためである。

## 試す

<RunCommand id="goddard_0knot" />

- `n = [50]` を `[30]` や `[80]` に変え、推力の振動と `max altitude` を比較する。
- `self.Vc`（抗力係数）を小さくし、特異弧が縮むことを確認する。
