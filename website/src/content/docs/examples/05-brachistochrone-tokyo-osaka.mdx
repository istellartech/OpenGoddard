03の最速降下を実寸に拡大し、終点を出発点と同じ高さに固定する。位置が $10^5$ m 規模になるため、単位スケーリングを用いる。

## 問題

$g = 9.8$ m/s²、$l = 600\,000$ m とする。重力は一様とし、地球の曲率と摩擦は無視する。

$$
\dot{x} = v\sin\theta,\quad \dot{y} = v\cos\theta,\quad \dot{v} = g\cos\theta,\qquad
x(0)=y(0)=v(0)=0,\quad x(t_f)=l,\quad y(t_f)=0,
$$

$$
0 \le x \le l,\quad y \ge 0,\quad 0 \le \theta \le \pi,\qquad J = t_f
$$

解析解はサイクロイドの1周分で、$a = l/(2\pi) \approx 95.5$ km、最大深さ $2a \approx 191$ km、$t_f = 2\pi\sqrt{a/g} \approx 620$ s である。

## 手で書く順序

03と同じ運動方程式に実距離と重力を入れる。`set_unit_*` の値をたどり、数式に使う物理単位と、最適化内部の単位を区別する。

## コードとの対応

| 数式 | 例題のPythonファイル |
| --- | --- |
| 運動方程式 | `dynamics` の `dx[0] = v * np.sin(theta)`、`dx[1] = v * np.cos(theta)`、`dx[2] = g * np.cos(theta)` |
| 境界条件・不等式制約 | `equality` の `result.equal(...)` 5本、`inequality` の `lower_bound` / `upper_bound` |
| $J = t_f$ | `cost` が `problem.time_final(-1)` を返し |
| スケーリング | `unit_x = 300000`、`unit_y = 100000`、`unit_t = 100`、`unit_v = unit_x / unit_t` |
| 初期推定・求解 | ノード数 `[30]`、$\theta$ は 0→$\pi$ の直線、`problem.solve(parameters, maxiter=2000)` |

## 結果

軌道・速さ・$\theta$ をサイクロイドと比較する。到達時刻は約 620 s で解析解と一致する。

<ExampleMedia id="brachistochrone_tokyo_osaka" />

- 軌道は左右対称で、中央で最大深さ約 190 km、最大速さ約 1.9 km/s に達する。
- $\theta$ は 0° から 180° まで時間にほぼ比例して増加する。
