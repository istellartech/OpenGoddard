<p class="lead">
  例題は簡単なものから順に並んでいます。どの例題も、1つの物理モデルと1つの目的関数だけを扱い、
  1つの Python ファイルで条件設定から描画まで完結します。
</p>

各ページでは、まず問題の状況と数式（運動方程式・境界条件・制約・目的関数）を説明し、
次に OpenGoddard で解いた結果の図と動画を示します。図の点は計算で直接求めたノードでの値、線はそれらを通る多項式です。
解析解がある例題では、黒の破線で重ねて示します。

## 軌道投入と軌道遷移

<ExampleCards numbers={['12', '13', '14', '15']} />

## 例題の実行

リポジトリのルートで次のように実行します（環境の準備は[はじめに](../#インストール)を参照）。

```sh
uv run python examples/07_goddard_0knot.py
```

各ファイルの `PARAMETERS`（または `Rocket` クラス）の値を変えると、条件を変えて解き直せます。
