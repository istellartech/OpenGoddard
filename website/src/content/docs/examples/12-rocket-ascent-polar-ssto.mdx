単段ロケット（SSTO）を地表から高度 400 km の円軌道に投入します。地心距離 $R$ と角度 $\theta$ の
極座標で平面内の運動を表し、推力の向きも半径方向・周方向の2成分として最適化します。

## 問題

状態は $(R, \theta, V_r, V_t, m)$、制御は推力成分 $(T_r, T_t)$ です。$V_t^2/R$ は遠心力、$-V_rV_t/R$ はコリオリ項です。

$$
\dot{R} = V_r,\quad \dot{\theta} = \frac{V_t}{R},\quad
\dot{V}_r = \frac{T_r - D_r}{m} - g + \frac{V_t^2}{R},\quad
\dot{V}_t = \frac{T_t - D_t}{m} - \frac{V_r V_t}{R},\quad
\dot{m} = -\frac{\sqrt{T_r^2+T_t^2}}{g_0 I_{sp}}
$$

$g = g_0(R_e/R)^2$、$\rho = 1.225\,e^{-h/8500}$、抗力は速度の向きに $D_{r,t} = \tfrac12 \rho V_{r,t} \lvert V\rvert C_d A$ です
（$M_0 = 100$ t、$C_d = 0.6$、$A = 4$ m²、$I_{sp} = 300$ s、$T_{\max} = 1.5 M_0 g_0$）。
地表で静止状態から出発し、終端で円軌道に入ります。円軌道は「半径が目標値、半径方向速度 0、周方向速度が円軌道速度」の3本で表せます。

$$
\begin{aligned}
&R(0)=R_e,\ \theta(0)=V_r(0)=V_t(0)=0,\ m(0)=M_0;\qquad
R(t_f)=R_e+400\,\mathrm{km},\ V_r(t_f)=0,\ V_t(t_f)=\sqrt{GM_e/R(t_f)} \\
&\sqrt{T_r^2+T_t^2} \le T_{\max},\quad 0 \le T_r, T_t \le T_{\max},\quad
\lvert \boldsymbol{T}-\boldsymbol{D}\rvert/m \le 8 g_0,\quad m \ge 0.01 M_0,\qquad
J = -m(t_f)/M_0
\end{aligned}
$$

$\theta(t_f)$ と $t_f$ は自由です。

## コードとの対応

| 数式 | `main.py` |
| --- | --- |
| 遠心力・コリオリ項 | `dx[2] = Tr / m - Dr / m - g + Vt**2 / R`、`dx[3] = Tt / m - Dt / m - (Vr * Vt) / R` |
| 質量流量 | `dx[4] = -np.sqrt(Tr**2 + Tt**2) / g0 / Isp` |
| 抗力 | `Dr = 0.5 * rho * Vr * np.sqrt(Vr**2 + Vt**2) * obj.Cd * obj.A` |
| 円軌道投入 | `result.equal(R[-1], obj.Rtarget, ...)`、`Vr[-1]` を 0、`Vt[-1]` を `obj.Vtarget` |
| 推力の大きさ・加速度 | `result.upper_bound(T, obj.Tmax, ...)`、`result.upper_bound(a_mag, obj.MaxG * obj.g0)` |
| 成分の範囲 | `prob.set_controls_bounds_all_section(0, 0.0, obj.Tmax)`（`1` も同様） |
| $J$ | `cost` が `-m[-1] / prob.unit_states[0][4]` を返す |

`set_unit_*` で長さ $R_e$、速度 $\sqrt{GM_e/R_e}$、質量 $M_0$ を単位にし、桁の違う量を 1 前後に揃えています。
求解は `ftol=1e-6, maxiter=3000` の1回の長い SLSQP 実行です。既定の `maxiter=25` で再起動を繰り返すと、
そのたびにヘッセ行列の推定が捨てられて収束しませんでした。

## 結果

推力が切れて長く慣性飛行し、遠地点で短く水平に噴射する流れに注目してください。

<ExampleMedia id="rocket_ascent_polar_ssto" />

- 最初は最大推力で上昇し、推力の仰角は上向きから徐々に寝ていきます。濃い大気を抜けてから水平加速に推力を回す、重力ターンに近い形です。
- 噴射を止めた後は長い慣性飛行で、$V_r$ が 0 になる高度 400 km が遠地点です。
- 遠地点でほぼ水平に短く噴射し、周方向速度を円軌道速度（約 7.67 km/s）まで上げます。ホーマン遷移の2回目の噴射と同じ考え方です。
- 最終質量は約 4.4 t で、構造 1 t を除いた残りがペイロードに回せる推進剤の余裕です。
- 慣性飛行中は推進剤を使わないので、最終質量は慣性飛行の長さにほとんど依存しません。そのため慣性飛行の長さと $t_f$ は計算環境によって変わります。
