単段ロケット（SSTO）を地表から高度 400 km の円軌道へ投入する。平面運動を極座標 $(R, \theta)$ で表し、推力の半径方向・周方向成分を最適化する。

## 問題

状態 $(R, \theta, V_r, V_t, m)$、制御 $(T_r, T_t)$。$V_t^2/R$ は遠心力項、$-V_rV_t/R$ はコリオリ項である。

$$
\dot{R} = V_r,\quad \dot{\theta} = \frac{V_t}{R},\quad
\dot{V}_r = \frac{T_r - D_r}{m} - g + \frac{V_t^2}{R},\quad
\dot{V}_t = \frac{T_t - D_t}{m} - \frac{V_r V_t}{R},\quad
\dot{m} = -\frac{\sqrt{T_r^2+T_t^2}}{g_0 I_{sp}}
$$

$g = g_0(R_e/R)^2$、$\rho = 1.225\,e^{-h/8500}$、$D_{r,t} = \tfrac12 \rho V_{r,t} \lvert V\rvert C_d A$、$M_0 = 100$ t、$C_d = 0.6$、$A = 4$ m²、$I_{sp} = 300$ s、$T_{\max} = 1.5 M_0 g_0$。$\theta(t_f)$ と $t_f$ は自由である。

$$
\begin{aligned}
&R(0)=R_e,\ \theta(0)=V_r(0)=V_t(0)=0,\ m(0)=M_0;\qquad
R(t_f)=R_e+400\,\mathrm{km},\ V_r(t_f)=0,\ V_t(t_f)=\sqrt{GM_e/R(t_f)} \\
&\sqrt{T_r^2+T_t^2} \le T_{\max},\quad 0 \le T_r, T_t \le T_{\max},\quad
\lvert \boldsymbol{T}-\boldsymbol{D}\rvert/m \le 8 g_0,\quad m \ge 0.01 M_0,\qquad
J = -m(t_f)/M_0
\end{aligned}
$$

## 手で書く順序

半径・角度・2成分の速度・質量を添字0〜4に対応させる。まず重力と極座標の運動方程式を書き、次に推力成分と軌道投入条件を追加する。

## コードとの対応

| 数式 | 例題のPythonファイル |
| --- | --- |
| 遠心力・コリオリ項 | `dx[2] = Tr / m - Dr / m - g + Vt**2 / R`、`dx[3] = Tt / m - Dt / m - (Vr * Vt) / R` |
| 円軌道投入 | `result.equal(R[-1], obj.Rtarget, ...)`、`Vr[-1]` を 0、`Vt[-1]` を `obj.Vtarget` |
| 推力の大きさ・加速度 | `result.upper_bound(T, obj.Tmax, ...)`、`result.upper_bound(a_mag, obj.MaxG * obj.g0)` |
| $J$ | `cost` が `-m[-1] / problem.unit_states[0][4]` を返す |

`set_unit_*` で長さ・速度・質量を $R_e$、$\sqrt{GM_e/R_e}$、$M_0$ で正規化する。求解は `ftol=1e-6, maxiter=3000` の1回の SLSQP 実行である。

## 結果

上昇噴射、長い慣性飛行、遠地点での水平な円軌道化噴射の3段階になる。

<ExampleMedia id="rocket_ascent_polar_ssto" />

- 上昇中は最大推力で、推力方向は上向きから徐々に水平へ倒れる。慣性飛行の遠地点が高度 400 km になり、そこで周方向に短く噴射して円軌道速度（約 7.67 km/s）に達する。最終質量は約 4.4 t である。
- 最終質量は慣性飛行の長さにほとんど依存しないため、慣性飛行の長さと $t_f$ は計算環境によって変わる。
