推力の大きさが一定のロケットを推力の向き $\beta$ だけで操作し、高さ $y = 1$ を水平速度 1 で飛ぶ状態に最短時間で入れる。軌道投入を単純化した問題である。

## 問題

重力と質量変化はなく、加速度の大きさは $a = 1$ で一定（無次元）。$x(t_f)$ は自由。

$$
\dot{u} = a\cos\beta,\quad \dot{v} = a\sin\beta,\quad \dot{x} = u,\quad \dot{y} = v,\qquad
u(0)=v(0)=x(0)=y(0)=0
$$

$$
u(t_f)=1,\quad v(t_f)=0,\quad y(t_f)=1,\qquad -\tfrac{\pi}{2} \le \beta \le \tfrac{\pi}{2},\qquad J = t_f
$$

## コードとの対応

| 数式 | `main.py` |
| --- | --- |
| 運動方程式 | `pointwise_dynamics` の `xp.stack((obj.a * xp.cos(u[0]), obj.a * xp.sin(u[0]), x[0], x[1]))` |
| 境界条件 | `equality` の `result.equal(...)` 7本 |
| $\beta$ の範囲 | `result.lower_bound(beta, -np.pi / 2)` ほか |
| $J = t_f$ | `cost` が `prob.time_final(-1)` を返す（`cost_derivative = None`） |
| 離散化 | `n = [20]`、`time_init = [0.0, 2.0]` |
| 初期推定 | $y$ に `3 * fraction**2 - 2 * fraction**3` など境界条件を満たす多項式 |

`pointwise_dynamics` では `x[0]` が水平速度 $u$、`u[0]` が制御 $\beta$ である。

## 結果

ロケットの軌道と、$u$、$v$、$\beta$ の時間履歴を示す。

<ExampleMedia id="simple_rocket_2d" />

- 到達時刻は約 2.08、終点の $x$ は約 1.04。
- $\beta$ は約 +77° から 0° を経て約 −77° まで単調に回転する。
- $v$ は中央で最大となり、終点で 0 に戻る。
