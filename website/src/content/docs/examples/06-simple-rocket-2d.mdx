推力の大きさが一定のロケットを、推力の**向き**だけを操作して飛ばします。
目標は高さ $y = 1$ で上下方向の速度を 0 にし、水平方向の速度 1 を得ること、つまり
「決められた高度で水平に飛ぶ状態」に最短時間で入ることです。ロケットの軌道投入を
極限まで単純化した問題で、後のロケット上昇の例題につながる考え方を含みます。

## この例題で学ぶこと

- 制御が角度1つで、状態が2次元の位置と速度の4個になる問題の組み立て方
- 終点で一部の状態（水平位置 $x$）を自由にした最短時間問題
- 終端の速度条件を満たすために、推力方向が時間とともに上向きから下向きへ回転する理由

## 問題設定

状態は水平速度 $u$、鉛直速度 $v$、水平位置 $x$、高さ $y$ の4個、
制御は推力方向の角度 $\beta$（水平から上向きを正）です。
加速度の大きさ $a$ は一定で、`Rocket` クラスの値は $a = 1$ です（無次元量で、重力や質量変化は含みません）。

$$
\dot{u} = a\cos\beta, \qquad \dot{v} = a\sin\beta, \qquad \dot{x} = u, \qquad \dot{y} = v
$$

境界条件と制約は次のとおりです。

$$
u(0) = v(0) = x(0) = y(0) = 0, \qquad u(t_f) = 1, \qquad v(t_f) = 0, \qquad y(t_f) = 1,
\qquad -\frac{\pi}{2} \le \beta \le \frac{\pi}{2}
$$

$x(t_f)$ には条件を課しません。目的関数は到達時刻 $J = t_f$ です。

高さ 1 まで上がるには上向きに加速する必要がありますが、終点では鉛直速度を 0 に戻さなければなりません。
そのため推力は最初は上向き、途中で水平を通り、最後は下向きになります。
同時に水平方向にも常に加速し続け、終点で $u = 1$ に揃えます。

## 数式とコードの対応

| 数式 | コード（`main.py`） |
| --- | --- |
| $\dot{u}=a\cos\beta,\ \dot{v}=a\sin\beta,\ \dot{x}=u,\ \dot{y}=v$ | `pointwise_dynamics` の `xp.stack((obj.a * xp.cos(u[0]), obj.a * xp.sin(u[0]), x[0], x[1]))` |
| $u(0)=v(0)=x(0)=y(0)=0$ | `equality` の `result.equal(u[0], 0.0)` など4本 |
| $u(t_f)=1,\ v(t_f)=0,\ y(t_f)=1$ | `result.equal(u[-1], 1.0)`、`result.equal(v[-1], 0.0)`、`result.equal(y[-1], 1.0)` |
| $-\pi/2 \le \beta \le \pi/2$ | `inequality` の `result.lower_bound(beta, -np.pi / 2)` と `result.upper_bound(beta, np.pi / 2)` |
| $J = t_f$ | `cost` が `prob.time_final(-1)` を返す（`cost_derivative = None` なので勾配は OpenGoddard が自動で求める） |
| ノード数・初期時刻区間 | `n = [20]`、`time_init = [0.0, 2.0]` |
| 初期推定 | `fraction` を正規化時間として、$u$ は直線、$y$ は `3 * fraction**2 - 2 * fraction**3` などの多項式 |

`pointwise_dynamics` の引数 `x` は状態ベクトル全体、`u` は制御ベクトルです。
`x[0]` は水平速度 $u$、`u[0]` は角度 $\beta$ を指すので、数式の記号とコードの変数名の対応に注意してください。

初期推定は、境界条件をすべて満たす多項式で作られています。コード中のコメントのとおり、
全変数が 0 の推定から始めると特異になりやすいため、意味のある軌道から出発させています。

### 読み取りのポイント

- 到達時刻は約 2.085 で、終点の水平位置は約 1.043 です。$x(t_f)$ は自由なので、ソルバーが決めた値です。
- $\beta$ は約 +77°（ほぼ上向き）から始まり、時間の中央で 0°（水平）を通り、約 −77° まで単調に回転します。
- 鉛直速度 $v$ は中央で最大（約 0.84）になり、終点で 0 に戻ります。高さ $y$ はS字状に 1 へ近づきます。
- 水平速度 $u$ は $\cos\beta$ が小さい始めと終わりでゆっくり、中央で速く増え、終点で 1 に揃います。
- `main.py` が保存する図には、`n = [20]` のノード上の値が点で描かれています。

## 試してみる

<RunCommand id="simple_rocket_2d" />

求解後に時間履歴と軌道の図を表示し、`output/` に保存します。`main.py` の値を変えてみましょう。

- `Rocket` の `a` を 2 にすると、到達時刻と推力角の変化はどう変わるでしょうか。
- `equality` の `result.equal(y[-1], 1.0)` を 2 に変えると、より高く上がるために最初の上向きの角度が大きくなるはずです。
- 計算した $\beta$ について $\tan\beta$ を時間に対してプロットしてみましょう。おおむね直線になるはずです。
  一定加速度・重力なしの最短時間問題で知られる「線形タンジェント則」です。
- `n = [20]` を `[10]` や `[40]` に変えて、到達時刻がどれだけ変わるか比べてみましょう。
