[12](../12-rocket-ascent-polar-ssto/) の極座標モデルを2段ロケットに広げ、高度 500 km の円軌道に投入します。
各段の燃焼を1つの phase とし、段分離では位置と速度を連続、質量だけを2段目の初期質量に切り替えます。

## 問題

状態 $(R, \theta, V_r, V_t, m)$、制御 $(T_r, T_t)$、運動方程式は12と同じで、$i$ 段目の phase ではその段の値を使います。

$$
\dot{m} = -\frac{\sqrt{T_r^2+T_t^2}}{g_0 I_{sp,i}},\qquad
D_{r,t} = \tfrac12 \rho V_{r,t} \lvert V\rvert C_{d,i} A_i
$$

| | 1段目 | 2段目 |
| --- | --- | --- |
| 初期質量・乾燥質量 | 20000 kg・2000 kg | 1000 kg・200 kg |
| $I_{sp}$ | 300 s | 350 s |
| 最大推力 $1.5 M_{0,i} g_0$ | 約 294 kN | 約 14.7 kN |

$$
\begin{aligned}
&R(0)=R_e,\ \theta(0)=V_r(0)=V_t(0)=0,\ m(0)=20000;\qquad
R(t_f)=R_e+500\,\mathrm{km},\ V_r(t_f)=0,\ V_t(t_f)=\sqrt{GM_e/R(t_f)} \\
&(R,\theta,V_r,V_t)(t_s^+) = (R,\theta,V_r,V_t)(t_s^-),\qquad m(t_s^+) = 1000 \\
&\sqrt{T_r^2+T_t^2} \le T_{\max,i},\quad \lvert \boldsymbol{T}-\boldsymbol{D}\rvert/m \le 8 g_0,\quad
2000 \le m \le 20000\ (\text{1段目}),\quad 1 \le m \le 1000\ (\text{2段目}),\qquad
J = -m(t_f)/M_{0,1}
\end{aligned}
$$

分離時刻 $t_s$ と $t_f$ は最適化変数です。

## コードとの対応

| 数式 | `main.py` |
| --- | --- |
| 段ごとの値 | `Isp = obj.Isp[section]`、`obj.Cd[section] * obj.A[section]` |
| knot での自動連続を外す | `prob.dynamics = [dynamics, dynamics]`、`prob.knot_states_smooth = [False]` |
| 位置・速度の連続 | `result.equal(R1[0], R0[-1], unit=unit_R)`（`theta`、`Vr`、`Vt` も同様） |
| 段分離後の質量 | `result.equal(m1[0], obj.M0[1], unit=unit_m)` |
| 段ごとの推力上限 | `result.upper_bound(T0, obj.Tmax[0], ...)`、`result.upper_bound(T1, obj.Tmax[1], ...)` |
| 質量の範囲 | `prob.set_states_bounds(4, 0, obj.Mdry[0], obj.M0[0])`、`prob.set_states_bounds(4, 1, 1.0, obj.M0[1])` |
| $J$ | `cost` が `-m1[-1] / prob.unit_states[1][4]` を返す |

`R0 = prob.states(0, 0)` は phase 0、`R1 = prob.states(0, 1)` は phase 1 の値です。
質量は連続条件の代わりに $m(t_s^+) = 1000$ を課すので、分離で1段目の残りが捨てられます。
求解は12と同じく `ftol=1e-6, maxiter=3000` の1回の長い SLSQP 実行です（再起動でヘッセ行列の推定を捨てないため）。

## 結果

分離時刻の破線で質量が段差になり、高度・速度はつながっていることを確認してください。

<ExampleMedia id="rocket_ascent_polar_tsto" />

- 1段目は質量の下限 2000 kg まで燃え尽き、分離で質量は 1000 kg へ落ちます。推力の上限も約 294 kN から約 14.7 kN に変わります。
- 2段目は低い高度で円軌道速度より速く加速し、高度 500 km に遠地点を持つ楕円軌道に乗ります。
- 長い慣性飛行の後、遠地点で小さく水平に噴射して円軌道に入ります。ホーマン遷移に近い使い方です。
- 最終質量は約 477 kg です。
- 慣性飛行中は推進剤を使わないので、最終質量は慣性飛行の長さにほとんど依存しません。そのため慣性飛行の長さと $t_f$ は計算環境によって変わります。
