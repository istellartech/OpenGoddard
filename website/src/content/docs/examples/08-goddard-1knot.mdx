[07](../07-goddard-0knot/) と同じ問題を、推力がゼロになる時刻で2つの phase に分けて解く。phase の境界を knot と呼ぶ。

## 問題

運動方程式・境界条件・経路制約・目的関数は 07 と同じ。時間区間を knot 時刻 $t_1$ で $[0, t_1]$ と $[t_1, t_f]$ に分け、knot では状態のみを連続とする。

$$
h(t_1^-) = h(t_1^+),\quad v(t_1^-) = v(t_1^+),\quad m(t_1^-) = m(t_1^+),\qquad t_1 = 0.075
$$

各 phase は1本の多項式で近似されるため、推力の不連続を knot に置けば phase 内部の振動が消える。$t_1$ は 07 の解で推進剤が尽きる時刻付近に固定する。

## コードとの対応

| 数式 | `main.py` |
| --- | --- |
| 2つの phase | `time_init = [0.0, 0.1, 0.3]`、`n = [25, 25]` |
| 両 phase の運動方程式 | `prob.dynamics = [dynamics, dynamics]` |
| knot での状態の連続 | `prob.knot_states_smooth = [True]` |
| $t_1 = 0.075$ | `result.equal(ts0, 0.075)` |
| phase ごとの推力の初期推定 | `Guess.linear(prob.time[0], 3.5, 3.5)` と `Guess.linear(prob.time[1], 0.0, 0.0)` を `np.hstack` |
| $J$ の勾配 | `cost_derivative` が `-prob.unit_states[-1][0]` を設定 |

`knot_states_smooth = [True]` は、前の phase の最終ノードと次の phase の初期ノードで全状態が等しいという等式制約を加える。制御には課さないため、推力は knot で不連続になれる。

## 結果

軌道と推力・速度・質量の時間履歴を示す。

<ExampleMedia id="goddard_1knot" />

- 推力は knot で 0 に跳び、phase 1 では振動なく 0 のままである。
- 速度は knot で最大（約 0.131）となり、折れ曲がるが連続である。
- 最高高度は $h(t_f) \approx 1.0128$ で、合計ノード数 50 の 07 と同等である。

## 試す

<RunCommand id="goddard_1knot" />

- `result.equal(ts0, 0.075)` を削除し、knot 時刻も最適化変数とする。
- `knot_states_smooth = [False]` とし、状態が knot で不連続になることを確認する。
