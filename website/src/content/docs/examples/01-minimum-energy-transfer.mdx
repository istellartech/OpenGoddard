速度 $u$ を操作して位置 $x$ を距離 $d$ だけ動かす。`Problem` を組み立てる最小の手順を解析解と照合する。

## 問題

$$
\dot{x} = u,\qquad x(t_0)=0,\quad x(t_f)=d,\qquad 0 \le u \le 3,\quad 5.1 \le t_f \le 15,\qquad
J = (t_f - t_0) + \int_{t_0}^{t_f} u^2\,dt
$$

$t_0 = 5$、$d = 2$ とする。$u = d/T$ 一定のとき $J = T + d^2/T$ となり、最適解は $T = d$、$u = 1$、$J = 2d$ である。

## 手で書く順序

関数、NumPy配列の添字、ライブラリへの関数の登録を使う。まず `dynamics`、`equality`、`cost`、`running_cost` を順に書き、最後に `make_problem` と求解処理をつなぐ。

## コードとの対応

| 数式 | 例題のPythonファイル |
| --- | --- |
| $\dot{x}=u$ | `dynamics` の `dx[0] = u` |
| 境界条件 | `conditions.equal(x[0], 0)`、`conditions.equal(x[-1], target)` |
| $0 \le u \le 3$、$5.1 \le t_f \le 15$ | `set_controls_bounds(0, 0, 0, 3)`、`set_time_final_bounds(0, 5.1, 15)` |
| $t_f - t_0$ | `cost` が所要時間を返す |
| $\int u^2 dt$ | `running_cost` が `u**2` を返す（ガウス求積で積分） |
| 区間・ノード数・状態数・制御数 | `Problem([5, 8], [8], [1], [1], maxIterator=2)` |

## 結果

位置 $x$ と制御 $u$ を解析解 $x = t - 5$、$u = 1$ と比較する。

<ExampleMedia id="minimum_energy_transfer" />

- 所要時間は $T = 2$、目的関数は $J = 4$ で、解析解と一致する。
- $u$ の上限と $t_f$ の上下限はいずれも有効にならない。

## 試す

<RunCommand id="minimum_energy_transfer" />

- `main()` の `target` を 3 にし、$T = 3$、$J = 6$ となることを確認する。
- `set_controls_bounds` の上限を 0.5 にし、$u = 0.5$、$T = 2d$ となることを確認する。画面に表示する解析解は速度上限が無効な場合のものなので、この条件では使えない。
