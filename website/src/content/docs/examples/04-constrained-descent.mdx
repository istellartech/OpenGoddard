03の最速降下に「これより深くは潜れない」床を加えます。床が十分深ければ解はサイクロイドのままですが、
浅くなると軌道は床に接し、降下・床に沿った移動・上昇の3区間に分かれます。この区間構成を phase で表します。

## 問題

運動方程式は03と同じです（$y$ は下向き正、$\theta$ は鉛直下向きから測る）。静止から出発するので
エネルギー保存 $y = v^2/(2g)$ が成り立ち、コードでは状態を $x$ と $v$ の2個に減らします。
床の上で $\dot{y}=0$ と $\dot{v}=0$ を重複して課さないためです。

$$
\dot{x} = v\sin\theta,\quad \dot{v} = g\cos\theta,\qquad
x(0)=v(0)=0,\quad x(t_f)=L,\quad v(t_f)=\sqrt{2g\,y_f},\qquad
v \le \sqrt{2g\,y_{\max}},\qquad J = t_f
$$

03と違い終点の深さ $y_f$ も固定し、床 $y \le y_{\max}$ は速さの上限に置き換えます。
既定値は $L = 1$ m、$y_f = 0.2$ m、$g = 9.81$ m/s²、$y_{\max} = 0.3$ m です。

`reference_solution()` は、終点を通るサイクロイドの最大深さが $y_{\max}$ を超えるときに床が効くと判定し、
半径 $a = y_{\max}/2$ のサイクロイドで降下 → 速さ $\sqrt{2g\,y_{\max}}$ の等速移動 → 同じサイクロイドで上昇、
という解析解を作ります。これを phase 数（1 または 3）と初期推定、検証に使います。

## コードとの対応

| 数式 | `main.py` |
| --- | --- |
| 運動方程式 | `pointwise_dynamics` が `xp.stack((x[1] * xp.sin(theta), obj.gravity * xp.cos(theta)))` を返す |
| 終点 | `equality` の `c.equal(problem.states(0, -1)[-1], p.distance, ...)` と `np.sqrt(2 * p.gravity * p.final_depth)` |
| 床への出入り | 3区間のとき区間1・2の終端で `c.equal(..., floor_speed, ...)` |
| $v \le \sqrt{2g\,y_{\max}}$ | `problem.set_states_bounds(1, section, 0, np.sqrt(2 * p.gravity * p.max_depth) ...)` |
| $J = t_f$ | `problem.cost = LinearCallback(lambda prob, obj: prob.time_final(-1) / time_scale)` |
| 区間数・初期推定 | `make_problem()` が `reference_solution(p)["phase_durations"]` から決める |
| 深さの復元 | `solve()` で `depth = speed ** 2 / (2 * parameters.gravity)` |

床の上では $\theta$ を指定していません。速さが一定なので $\dot{v} = g\cos\theta = 0$ から $\theta = 90°$ が決まります。

## 結果

プリセットごとに、最適な経路の球と同じ終点への直線の斜面を滑る球を競争させています。最後の図は全プリセットの軌道の重ね描きです。

<ExampleMedia id="constrained_descent" />

- `no_floor`：終点 $(1, 0.2)$ を通るサイクロイド1区間で、途中約 0.358 m まで潜ります。到達時刻は約 0.621 s です。
- `default`：床 0.3 m が 0.358 m より浅いので3区間に分かれ、床の上では速さ一定・$\theta = 90°$ です。到達時刻は約 0.624 s とわずかに遅くなります。
- `inactive_floor`：床 0.8 m は効かず、`no_floor` と同じ解です。制約はあるだけでなく、効いたときに解を変えます。
- `shallow_floor`：床 0.23 m では床に沿う区間が長くなり、約 0.644 s に延びます。
- `lower_gravity`：$g = 1.62$ m/s² でも軌道の形は `default` と同じで、時間だけが $\sqrt{9.81/1.62} \approx 2.46$ 倍になります。
