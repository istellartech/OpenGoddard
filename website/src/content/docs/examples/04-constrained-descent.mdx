03の最速降下に床 $y \le y_{\max}$ を加える。床が有効な場合、解は降下・床上の等速移動・上昇の3区間となり、これを phase で表す。

## 問題

静止から出発するので $y = v^2/(2g)$ が成り立ち、状態を $x$ と $v$ の2個に減らす。床は速さの上限に置き換える。

$$
\dot{x} = v\sin\theta,\quad \dot{v} = g\cos\theta,\qquad
x(0)=v(0)=0,\quad x(t_f)=L,\quad v(t_f)=\sqrt{2g\,y_f},\qquad
v \le \sqrt{2g\,y_{\max}},\qquad J = t_f
$$

既定値は $L = 1$ m、$y_f = 0.2$ m、$g = 9.81$ m/s²、$y_{\max} = 0.3$ m である。`reference_solution()` は、
終点を通るサイクロイドの最大深さが $y_{\max}$ を超える場合に、半径 $y_{\max}/2$ のサイクロイドと等速区間からなる解析解を作り、
phase 数・初期推定・検証に用いる。

## コードとの対応

| 数式 | `main.py` |
| --- | --- |
| 運動方程式 | `pointwise_dynamics` が `xp.stack((x[1] * xp.sin(theta), obj.gravity * xp.cos(theta)))` を返す |
| 終点 | `c.equal(problem.states(0, -1)[-1], p.distance, ...)` と `np.sqrt(2 * p.gravity * p.final_depth)` |
| $v \le \sqrt{2g\,y_{\max}}$ | `problem.set_states_bounds(1, section, 0, np.sqrt(2 * p.gravity * p.max_depth) ...)` |
| $J = t_f$ | `problem.cost = LinearCallback(lambda prob, obj: prob.time_final(-1) / time_scale)` |
| 区間数・初期推定 | `make_problem()` が `reference_solution(p)["phase_durations"]` から決める |

## 結果

各プリセットの最適経路を、同じ終点への直線斜面と比較する。

<ExampleMedia id="constrained_descent" />

- `no_floor`：1区間のサイクロイドで、最大深さ約 0.358 m、到達時刻約 0.621 s である。
- `default`：床 0.3 m で3区間となり、床上では $\theta = 90°$ の等速移動となる。到達時刻は約 0.624 s である。
- `inactive_floor`：床 0.8 m は有効にならず、`no_floor` と同じ解になる。
