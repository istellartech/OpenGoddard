03の最速降下に「これより深くは掘れない」という床を加えます。
床が十分深ければ解はサイクロイドのままですが、床が浅くなると軌道は床に接し、
**下降・床上の水平移動・上昇**の3区間に分かれます。制約が効くかどうかで区間の構成が変わることと、
それを phase で表す方法を確かめる例題です。

## この例題で学ぶこと

- 状態の拘束（最大深さ）が効くと、解が性質の異なる区間に分かれること
- エネルギー保存を使って状態を減らし、冗長な運動方程式を避ける工夫
- 解析解（サイクロイド＋水平線分）を初期推定と検証の両方に使う方法

## 問題設定

水平位置 $x$ と深さ $y$（下向き正）、速さ $v$、制御 $\theta$（鉛直下向きから右向きに測った進行方向）は03と同じです。

$$
\dot{x} = v\sin\theta, \qquad \dot{y} = v\cos\theta, \qquad \dot{v} = g\cos\theta
$$

静止から出発するのでエネルギー保存により $y = v^2/(2g)$ が常に成り立ちます。
そこでコードでは状態を $x$ と $v$ の2個に減らし、深さは出力時に $v$ から復元します。
床の上では深さも速さも一定なので、$\dot{y}$ と $\dot{v}$ を両方課すと同じ条件が重複するためです。

境界条件は、03と違って終点の水平位置と深さの**両方**を固定します（深さの条件は速さの条件に置き換えます）。

$$
x(0) = v(0) = 0, \qquad x(t_f) = L, \qquad v(t_f) = \sqrt{2 g\, y_f}
$$

床の深さを $y_{\max}$ とすると、深さの制約 $y \le y_{\max}$ は速さの上限 $v \le \sqrt{2 g\, y_{\max}}$ になります。
目的関数は到達時刻 $t_f$ です（ソルバーには $t_f/\sqrt{L_s/g}$、$L_s = \max(L, y_f)$ の無次元値を渡します）。

`Parameters` の既定値は $L = 1$ m、$y_f = 0.2$ m、$g = 9.81$ m/s²、$y_{\max} = 0.3$ m です。

### 区間の分け方と解析解

`reference_solution()` は、まず床がない場合のサイクロイド $x = a(\phi - \sin\phi)$、$y = a(1-\cos\phi)$ を
終点 $(L, y_f)$ を通るように求めます。その最大深さ $2a$ が $y_{\max}$ を超える場合に床が効くと判定し、
次の3区間の解析解を作ります。

1. 下降：$a = y_{\max}/2$ のサイクロイドで、$\phi = \pi$（水平）で床に接する
2. 床上：深さ $y_{\max}$、速さ $\sqrt{2 g\, y_{\max}}$ の等速直線運動
3. 上昇：同じサイクロイドの $\phi > \pi$ の部分で終点まで上がる

各区間の所要時間は $\pi\sqrt{a/g}$、水平距離 $/ \sqrt{2 g\, y_{\max}}$、$(\phi_f - \pi)\sqrt{a/g}$ です。
これを各 phase の初期時刻と初期推定に使い、合計 `minimum_time` を数値解と比べます。

## 数式とコードの対応

| 数式 | コード（`main.py`） |
| --- | --- |
| $\dot{x}=v\sin\theta,\ \dot{v}=g\cos\theta$ | `pointwise_dynamics` が `xp.stack((x[1] * xp.sin(theta), obj.gravity * xp.cos(theta)))` を返す |
| $y = v^2/(2g)$（深さの復元） | `solve()` の `phase[grid]["depth"] = ... ** 2 / (2 * parameters.gravity)` |
| $x(0)=v(0)=0$ | `equality` の `for state in range(2): c.equal(problem.states(state, 0)[0], 0, ...)` |
| $x(t_f)=L,\ v(t_f)=\sqrt{2gy_f}$ | `c.equal(problem.states(0, -1)[-1], p.distance, ...)` と `np.sqrt(2 * p.gravity * p.final_depth)` |
| 床への出入りで $v=\sqrt{2gy_{\max}}$ | 3区間のとき `c.equal(problem.states(1, 0)[-1], floor_speed, ...)` と区間1の終端も同様 |
| $v \le \sqrt{2gy_{\max}}$ | `problem.set_states_bounds(1, section, 0, np.sqrt(2 * p.gravity * p.max_depth) ...)` |
| $0 \le x \le L$ | `problem.set_states_bounds(0, section, 0, p.distance)` |
| $\theta$ の範囲 | 下降 $[0, \pi/2]$、上昇 $[\pi/2, \pi]$、それ以外 $[0, \pi]$（`angle_bounds`） |
| 各区間の長さ $> 0$ | `inequality` の `c.lower_bound(prob.time_final(section) - prob.time_start(section), 1e-6 * time_scale, ...)` |
| $J = t_f$ | `problem.cost = LinearCallback(lambda prob, obj: prob.time_final(-1) / time_scale)` |
| 区間数 | `make_problem()` が `reference_solution(p)["phase_durations"]` の長さ（1 または 3）で phase 数を決める |

区間の境界時刻は最適化変数で、床に入る・出る時刻はソルバーが決めます。
床上で $\theta$ を直接指定していない点に注意してください。速さが一定 $v = \sqrt{2gy_{\max}}$ であることから、
運動方程式 $\dot{v} = g\cos\theta = 0$ によって $\theta = \pi/2$（水平）が決まります。

## 計算結果

左は軌道上を動く球で、破線は床 $y_{\max}$ です（`no_floor` では描かれません）。
深さは下向きに描いています。右は速さと $\theta$ の時間履歴で、縦の点線は phase の境界、黒い縦線は動画の現在時刻です。
タブでプリセットを切り替えられます。動画のタイトルにある objective は無次元化した到達時刻です。

### 読み取りのポイント

- `no_floor`：床がない場合です。軌道は終点 $(1, 0.2)$ を通るサイクロイド1区間で、
  途中で約 0.358 m まで潜ってから終点へ上がります。到達時刻は約 0.621 s です。
- `default`：床 0.3 m が約 0.358 m より浅いので制約が効き、3区間に分かれます。
  床上では速さが一定、$\theta$ が 90° で平らになります。到達時刻は約 0.624 s で、床なしよりわずかに遅くなります。
- `inactive_floor`：床 0.8 m は解の最大深さより深いので、床があっても `no_floor` と同じ1区間の解になります。
  制約は「あるかどうか」ではなく「効くかどうか」で解を変えることが分かります。
- `shallow_floor`：床 0.23 m では床上の区間が長くなり（解析解で約 0.476 m）、到達時刻は約 0.644 s に延びます。
- `lower_gravity`：月面程度の $g = 1.62$ m/s² です。軌道の形は `default` と同じで、時間だけが
  $\sqrt{9.81/1.62} \approx 2.46$ 倍（約 1.536 s）になります。無次元化した objective は `default` と同じ値になるので、
  重力の比較には実時間を使ってください。

最後の比較図は全プリセットの重ね描きです。床が効くプリセットだけ軌道の底が平らになっていることを確認してください。

## 試してみる

プリセットは `--preset`、個別のパラメータは `--set 名前=値`（値はJSON）で変更できます。
結果のJSONには `reference.minimum_time`（解析解）が含まれ、数値解と比較できます。

<RunCommand id="constrained_descent" args="--preset shallow_floor --plot" />
<RunCommand id="constrained_descent" args="--set max_depth=0.35 --plot" />
<RunCommand id="constrained_descent" args="--set final_depth=0.1 --set max_depth=null --plot" />

- `max_depth` を 0.4 から 0.25 まで少しずつ浅くし、どこで区間が3つに分かれ始めるかを探してみましょう。
  境界は床なしの解の最大深さ（既定値では約 0.358 m）のはずです。
- `distance` を大きくすると、床なしの解はどこまで深く潜るでしょうか。同じ床でも効き方が変わります。
- `max_depth` は `final_depth` より大きくする必要があります。等しくするとエラーになる理由を考えてみましょう。
