高度 100 m を毎秒 10 m で降下している月着陸機が、**高度0・速度0で同時に**接地する推力履歴を求めます。
最小の推進剤で止まるには「しばらく自由落下し、最後に最大推力で一気に止める」のが最適です。
このとき推力の切り替え時刻と燃焼時間は解析的に求まるので、数値解をそれと比べて確かめられます。

## この例題で学ぶこと

- 「上向き正」の座標で、降下・着地の境界条件を符号に注意して書く方法
- 制御に線形なコスト（力積）から bang-bang 制御（推力0 → 最大推力）が現れる理由
- 解析解で coast / burn の2つの phase を初期化し、knot で状態を連続させる方法
- 質量一定モデルと質量可変（ロケット方程式）モデルの書き分け

## 問題設定

高度 $h$ と速度 $v$ は上向きを正、地表を $h = 0$ とします。一定重力・大気なし・姿勢運動なしのモデルです。
制御は推力 $T$ です。

$$
\dot{h} = v, \qquad \dot{v} = \frac{T}{m} - g, \qquad \dot{m} = -\frac{T}{v_e}
$$

既定（`variable_mass = false`）では $m = m_0$ を定数として状態を $h, v$ の2つにし、
`variable_mass = true` では質量 $m$ も状態に加えます。既定値は
$h_0 = 100$ m, $v_0 = -10$ m/s, $g = 1.62$ m/s², $m_0 = 1000$ kg, $T_{\max} = 4000$ N,
$v_e = 3000$ m/s, 乾燥質量 $m_{\rm dry} = 700$ kg です。

境界条件と制約は次のとおりです。

$$
h(0) = h_0, \quad v(0) = v_0, \quad h(t_f) = 0, \quad v(t_f) = 0, \qquad
0 \le h \le h_0, \quad v \le 0, \quad 0 \le T \le T_{\max}
$$

質量可変モデルではさらに $m(0) = m_0$, $m_{\rm dry} \le m \le m_0$ です。目的関数はモデルで変わります。

| モデル | 最小化するもの | 求解器に渡す値 |
| --- | --- | --- |
| 質量一定 | 総力積 $\displaystyle\int_0^{t_f} T\,dt$ | $\displaystyle\frac{1}{T_{\max}\sqrt{h_0/g}}\int_0^{t_f} T\,dt$ |
| 質量可変 | 推進剤消費率 | $1 - m(t_f)/m_0$ |

### 解析解（参照解）

質量一定のとき、コストは $T$ に線形なので最適推力は 0 か $T_{\max}$ のどちらかになり、
「自由落下（coast） → 最大推力（burn）」が最適です。減速度を $b = T_{\max}/m_0 - g$ とすると、
切り替え時の降下速さ $s$ は、coast のエネルギー保存 $s^2 = v_0^2 + 2g(h_0 - h_s)$ と、
burn での停止距離 $s^2 = 2 b h_s$ から $h_s$ を消去して得られます。

$$
s = \sqrt{\frac{(v_0^2 + 2 g h_0)\, b}{b + g}}, \qquad
t_{\rm coast} = \frac{s + v_0}{g}, \qquad
t_{\rm burn} = \frac{s}{b}, \qquad
I = T_{\max}\, t_{\rm burn}
$$

既定値では $t_{\rm coast} \approx 3.63$ s, $t_{\rm burn} \approx 6.67$ s, 力積 $I \approx 26695$ N·s です。
これが `constant_mass_reference()` です。

質量可変のときは、burn 中に質量が減って減速度が増えます。`burn_state()` が最大推力での
ロケット方程式の厳密解（$\Delta v = -v_e \ln(1 - \dot{m} t/m_0)$ を含む）を与え、
`landing_reference()` が「速度0になる時刻と高度0になる時刻が一致する」燃焼時間を
`brentq` で求めます。推進剤が足りない場合や初期 coast が成り立たない場合はエラーにします。

## 数式とコードの対応

| 数式 | コード（`main.py`） |
| --- | --- |
| $\dot{h}=v,\ \dot{v}=T/m-g$ | `pointwise_dynamics` の `acceleration = u[0] / mass - obj.gravity` |
| $\dot{m}=-T/v_e$（質量可変のみ） | `xp.stack((x[1], acceleration, -u[0] / obj.exhaust_velocity))` |
| $h(0)=h_0,\ v(0)=v_0$ | `equality` の `c.equal(problem.states(0, 0)[0], p.initial_altitude, ...)` など |
| $h(t_f)=0,\ v(t_f)=0$ | `c.equal(problem.states(0, -1)[-1], 0, ...)`, `c.equal(problem.states(1, -1)[-1], 0, ...)` |
| $0 \le h \le h_0,\ v \le 0$ | `set_states_bounds(0, section, 0, p.initial_altitude)`, `set_states_bounds(1, section, None, 0)` |
| $0 \le T \le T_{\max}$ | `set_controls_bounds(0, section, 0, p.max_thrust)` |
| $m_{\rm dry} \le m \le m_0$ | `set_states_bounds(2, section, p.dry_mass, p.initial_mass)` |
| 質量一定のコスト | `problem.running_cost = lambda prob, obj: prob.controls_all_section(0) / (obj.max_thrust * time_scale)` |
| 質量可変のコスト | `LinearCallback(lambda prob, obj: 1 - prob.states(2, -1)[-1] / obj.initial_mass)` |
| coast / burn の2 phase | `Problem([0, tc, tc + tb], [nodes] * 2, ...)`（`tc`, `tb` は `landing_reference()` から） |
| 各 phase の長さ 0 より大 | `inequality` の `c.lower_bound(prob.time_final(section) - prob.time_start(section), 1e-5 * time_scale, ...)` |

2つの phase は解析解の切り替え時刻で初期化しますが、**両方の phase で推力は 0〜$T_{\max}$ の間で自由**です。
coast phase で推力を0に固定しているわけではなく、最適化の結果として 0 になります。
`knot_states_smooth` は指定していないので既定値 `[True]` が使われ、knot で $h, v$（と $m$）は連続、
推力は不連続に変化できます。初期推定は coast では自由落下の放物線、burn では最大推力での減速
（質量可変なら `burn_state()`）です。

時間・高度・速度・推力は `set_unit_time(sqrt(h0/g))` などで正規化しています。
求解器の目的値（動画タイトルの `objective`）はこの無次元値なので、モードをまたいだ比較には
出力の `diagnostics.impulse_Ns` や `diagnostics.propellant_used_kg` を使います。

### 読み取りのポイント

- `default`：$t \approx 3.63$ s までは推力0で、速度は $-10$ m/s から $-g$ の傾きで直線的に速くなります。
  knot（高度約 53 m、降下速さ約 15.9 m/s）で推力が 0 から 4 kN に跳び、速度は傾き $b = 2.38$ m/s² で 0 に戻ります。
  $t_f \approx 10.31$ s で着地し、数値解の力積 26694.66 N·s は解析解と一致します。
- `variable_mass`：質量のグラフが加わります。$v_e = 3000$ m/s と大きいため消費量は約 8.84 kg と小さく、
  coast 約 3.64 s・着地約 10.27 s と、軌道は `default` とほとんど重なります（比較図で青線が赤線に隠れます）。
  燃焼中に軽くなる分だけ、わずかに遅く点火して早く着地します。
- `lower_thrust`：最大推力が 3 kN になり減速度 $b = 1.38$ m/s² が小さいので、約 2.45 s（高度約 71 m）と早めに点火し、
  長く（約 10.1 s）噴きます。着地は約 12.57 s、力積は約 30360 N·s に増えます。
- `higher_start`：初期高度 200 m。約 6.85 s 自由落下して約 21.1 m/s まで加速し、高度約 93 m で点火します。
  着地は約 15.71 s で、落下距離が長い分、重力に打ち勝つための力積（約 35456 N·s）が増えます。

## 試してみる

プリセットは `--preset`、個別のパラメータは `--set 名前=JSON値` で変更できます。

<RunCommand id="soft_landing" args="--set variable_mass=true --set exhaust_velocity=300 --plot" />
<RunCommand id="soft_landing" args="--set initial_velocity=-15 --set max_thrust=3500 --plot" />

- `exhaust_velocity` を 300 m/s に下げると、推進剤消費（`propellant_used_kg`）と点火時刻はどう変わるでしょうか。
  質量が大きく減るほど、質量一定の解析解とのずれが大きくなります。
- 質量可変モデルで `dry_mass` を `995` のように初期質量に近づけると、推進剤不足のエラーになります。
  どのくらいの推進剤が必要かを `propellant_used_kg` から見積もってみましょう。
- `max_thrust` を初期重量 $m_0 g = 1620$ N 以下にするとエラーになります。止まれない理由を運動方程式から考えてみましょう。
- `--nodes 6` のようにノード数を減らしても、bang-bang 解は解析解とよく一致するでしょうか。
