摩擦のない坂を重力だけで滑る球を、水平距離 $l$ 先へ最も早く届けるには坂をどんな形にすればよいか。
変分法の古典問題である最速降下を、坂の傾きを制御とする最適制御問題として解きます。終点の深さは自由です。

## 問題

状態は水平位置 $x$、深さ $y$（下向きが正）、速さ $v$、制御は進行方向が鉛直下向きからなす角 $\theta$ です。
`Ball` の値は $g = 1$、$l = 1$ です。

$$
\dot{x} = v\sin\theta,\quad \dot{y} = v\cos\theta,\quad \dot{v} = g\cos\theta,\qquad
x(0)=y(0)=v(0)=0,\quad x(t_f)=l,\qquad
y \ge 0,\quad \theta \ge 0,\quad t_f \ge 0.1,\qquad J = t_f
$$

$y(t_f)$ と $v(t_f)$ は自由です。解析解はサイクロイド $x = a(\phi - \sin\phi)$、$y = a(1-\cos\phi)$ で、
終点の深さが自由なら終点で水平（$\theta(t_f) = \pi/2$、$\phi = \pi$）となり $a = l/\pi$ です。
このとき $y(t_f) = 2l/\pi \approx 0.637$、$t_f = \pi\sqrt{a/g} = \sqrt{\pi} \approx 1.772$ です。

## コードとの対応

| 数式 | `main.py` |
| --- | --- |
| 運動方程式 | `pointwise_dynamics` の `xp.stack((x[2] * xp.sin(theta), x[2] * xp.cos(theta), obj.g * xp.cos(theta)))` |
| 境界条件 | `equality` の `result.equal(...)` 4本（終点は `result.equal(x[-1], obj.l)`） |
| $y \ge 0$、$\theta \ge 0$、$t_f \ge 0.1$ | `inequality` の `result.lower_bound(y[1:], 0)` など |
| $J = t_f$ | `cost` が `prob.time_final(-1)` を返す |
| $\partial J/\partial t_f$ | `cost_derivative` が `prob.unit_time` を入れる（$t_f$ は無次元化されているため） |
| ノード数・初期推定 | `n = [20]`、$\theta$ は一定 30°、$x$・$y$ は直線 |

## 結果

数値解の球と、同じ終点へ直線の斜面（解析解）を滑る球を競争させ、軌道・速さ・$\theta$ をサイクロイドと比べています。

<ExampleMedia id="brachistochrone" />

- 数値解の軌道はサイクロイドに重なり、到達時刻は約 1.772（$\sqrt{\pi}$）、終点の深さは約 0.637（$2l/\pi$）です。
- 直線の斜面は約 2.10 かかります。最初に真下へ落ちて速度を稼ぐほうが、距離は長くても速く着きます。
- $\theta$ は 0（真下）から始まり、終点でちょうど 90°（水平）になります。終点の深さを自由にしたことによる終端条件です。
- 速さはエネルギー保存 $v = \sqrt{2gy}$ に従い、サイクロイドでは $\theta$ が時間に比例して増えます。
