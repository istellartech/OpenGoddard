最速降下問題を、進行方向の角度を制御とする最適制御問題として解く。終点の深さは自由とする。

## 問題

$y$ は下向き正、$\theta$ は進行方向が鉛直下向きからなす角、$g = 1$、$l = 1$ である。

$$
\dot{x} = v\sin\theta,\quad \dot{y} = v\cos\theta,\quad \dot{v} = g\cos\theta,\qquad
x(0)=y(0)=v(0)=0,\quad x(t_f)=l,\qquad
y \ge 0,\quad \theta \ge 0,\quad t_f \ge 0.1,\qquad J = t_f
$$

解析解はサイクロイド $x = a(\phi - \sin\phi)$、$y = a(1-\cos\phi)$ である。終点の深さが自由なので終点で水平となり、
$a = l/\pi$、$y(t_f) = 2l/\pi \approx 0.637$、$t_f = \sqrt{\pi} \approx 1.772$ となる。

## 手で書く順序

三角関数を使って速さを水平・鉛直成分に分ける。まず3本の `dx` と初期条件を書く。終点の深さを固定していない点を、04との比較に使う。

## コードとの対応

| 数式 | 例題のPythonファイル |
| --- | --- |
| 運動方程式 | `dynamics` の `dx[0]`・`dx[1]`・`dx[2]` |
| 境界条件 | `equality` の `result.equal(...)` 4本（終点は `result.equal(x[-1], p["l"])`） |
| $y \ge 0$、$\theta \ge 0$、$t_f \ge 0.1$ | `inequality` の `result.lower_bound(y[1:], 0)` など |
| $J = t_f$ | `cost` が `problem.time_final(-1)` を返す |
| 勾配の計算 | ライブラリが有限差分で計算する |
| ノード数・初期推定 | ノード数 `[20]`、$\theta$ は一定 30°、$x$・$y$ は直線 |

## 結果

数値解を、サイクロイドおよび同じ終点への直線斜面と比較する。

<ExampleMedia id="brachistochrone" />

- 軌道はサイクロイドと一致し、到達時刻は約 1.772、終点の深さは約 0.637 である。
- 直線斜面の到達時刻は約 2.10 で、数値解より遅い。$\theta$ は 0 から始まり終点で 90° になる。
