物体を静止状態から距離 $d$ だけ動かして停止させる。目的関数と制約によって最適な加速度の形が変わる。

## 問題

$$
\dot{x} = v,\quad \dot{v} = u,\qquad
x(0)=v(0)=0,\quad x(t_f)=d,\quad v(t_f)=0,\qquad
|u| \le a_{\max},\quad 0 \le v \le v_{\max}
$$

| `objective` | 目的関数 | $t_f$ | 解析解 |
| --- | --- | --- | --- |
| `minimum_time` | $t_f$ | 自由 | 最大加速→（定速）→最大減速。速度上限なしで $t_f = 2\sqrt{d/a_{\max}}$ |
| `minimum_effort` | $\int_0^{t_f} u^2\,dt$ | 固定 | 制約が無効なら $u$ は時間の1次関数。$J = 12d^2/t_f^3$ |

## コードとの対応

| 数式 | `main.py` |
| --- | --- |
| $\dot{x}=v,\ \dot{v}=u$ | `pointwise_dynamics` が `xp.stack((x[1], u[0]))` を返す |
| 境界条件 | `equality` の `c.equal(...)` 4本 |
| $\lvert u\rvert \le a_{\max}$、$0 \le v \le v_{\max}$ | `set_controls_bounds`、`set_states_bounds` |
| $J=t_f$ / $J=\int u^2 dt$ | `problem.cost` / `problem.running_cost` |
| 区間の数と初期推定 | `phase_plan()`（加速度の切り替え時刻を phase 境界とする） |

## 結果

各プリセットの数値解を解析解（黒破線）と比較する。いずれも数値解は解析解と一致する。

<ExampleMedia id="move_stop" />

- `default`：加速度は $+a_{\max}$ から $-a_{\max}$ に1回切り替わり、速度は三角形になる。
- `speed_limit`：速度上限 2 m/s で定速区間が入り、速度は台形になる。
- `minimum_effort`：加速度は直線的に減少する。`limited_effort` では直線の両端が加速度上限で切り取られる。

## 試す

<RunCommand id="move_stop" args="--preset speed_limit --plot" />

- `--preset minimum_effort --set duration=5.5` を実行し、加速度上限が有効になることを確認する。
- `duration` を最短時間 $2\sqrt{d/a_{\max}}$ 以下にするとエラーになることを確認する。
