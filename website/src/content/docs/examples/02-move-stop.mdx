物体を静止状態から距離 $d$ だけ動かして止めます。同じ運動方程式でも、目的関数と制約によって
最適な加速度の形が変わります。解析解があるので、数値解と照合できます。

## 問題

状態は位置 $x$ と速度 $v$、制御は加速度 $u$ です。

$$
\dot{x} = v,\quad \dot{v} = u,\qquad
x(0)=v(0)=0,\quad x(t_f)=d,\quad v(t_f)=0,\qquad
|u| \le a_{\max},\quad 0 \le v \le v_{\max}
$$

| `objective` | 目的関数 | $t_f$ | 解析解 |
| --- | --- | --- | --- |
| `minimum_time` | $t_f$ | 自由 | 最大加速→最大減速（速度上限があれば間に定速）。$t_f = 2\sqrt{d/a_{\max}}$ |
| `minimum_effort` | $\int_0^{t_f} u^2\,dt$ | 固定 | 制約が効かなければ $u$ は時間の1次関数。$J = 12d^2/t_f^3$ |

加速度が切り替わる時刻を phase（区間）の境界にすると、各区間内で制御が滑らかになり、
多項式近似の精度が上がります。境界の時刻も最適化変数です。

## コードとの対応

| 数式 | `main.py` |
| --- | --- |
| $\dot{x}=v,\ \dot{v}=u$ | `pointwise_dynamics` が `xp.stack((x[1], u[0]))` を返す |
| 境界条件 | `equality` の `c.equal(...)` 4本 |
| $\lvert u\rvert \le a_{\max}$、$0 \le v \le v_{\max}$ | `set_controls_bounds`、`set_states_bounds` |
| $J=t_f$ / $J=\int u^2 dt$ | `problem.cost` / `problem.running_cost` |
| 区間の数と初期推定 | `phase_plan()`（解析解の切り替え構造） |

## 結果

プリセットはタブで切り替えられます。グラフの黒い破線は `phase_plan()` から計算した解析解です。

<ExampleMedia id="move_stop" />

- `default`：加速度は $+a_{\max}$ から $-a_{\max}$ に一度だけ切り替わり、速度は三角形です。
- `speed_limit`：速度が上限 2 m/s に達すると加速度 0 の定速区間が入り、速度は台形になります。
- `minimum_effort`：加速度は直線的に減り、急な切り替えがありません。
- `limited_effort`：時間を短くすると、直線の両端が加速度上限で切り取られます。
- どのプリセットでも、数値解は解析解に重なります。

## 試す

<RunCommand id="move_stop" args="--preset speed_limit --plot" />
<RunCommand id="move_stop" args="--preset minimum_effort --set duration=5.5 --plot" />

- `duration` を短くすると、どこから加速度上限に当たるか。最短時間 $2\sqrt{d/a_{\max}}$ 以下にするとエラーになるのはなぜか。
- `speed_limit` を変えると、所要時間はどれだけ延びるか。
