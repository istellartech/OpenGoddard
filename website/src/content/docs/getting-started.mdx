OpenGoddard は、連続時間の非線形最適制御問題を擬スペクトル法で非線形計画問題に変換し、SciPy で解く。
依存は NumPy・SciPy・Matplotlib のみである。

## インストール

Python 3.15 以上が必要である。

```sh
pip install OpenGoddard
```

例題を実行する場合は、リポジトリを取得して [uv](https://docs.astral.sh/uv/) で環境を構築する。

```sh
git clone https://github.com/istellartech/OpenGoddard.git
cd OpenGoddard
uv sync --locked
uv run python examples/01_minimum_energy_transfer.py
```

## 学習の進め方

まず01の `main()` の `target` を変えて実行し、次に `dynamics` と境界条件を自分で書く。
02以降はファイル冒頭の `PARAMETERS` を編集する。10〜14では `Rocket.__init__` に機体の条件をまとめる。
各ページの「手で書く順序」に沿って、すでに学んだ式に新しい状態や制約を追加していく。

01は普通の関数と配列の添字、02は加速・減速と区間接続、03は最速降下、04は深さの制約へと進む。
各例題は1つのモデルと目的関数に絞り、そのファイルだけで条件設定・計算・描画まで読める。
09は質量一定の着陸を扱う。燃料消費による質量変化は07のGoddard問題で学ぶ。
10〜14ではクラスに機体の条件をまとめ、段分離や大気モデルを順に追加する。

## 問題の記述

対象とする問題は次の形である。

$$
\min J = \Phi(x(t_f), t_f) + \int_{t_0}^{t_f} L(x, u, t)\, dt
\quad \text{s.t.}\quad \dot{x} = f(x, u, t),\ \ g = 0,\ \ h \ge 0
$$

[例題01](../examples/01-minimum-energy-transfer/)（$\dot{x}=u$、$x: 0 \to 2$、$J = T + \int u^2 dt$）での記述を示す。

`solve()` の第1引数はコールバックの第2引数（例題01では `target`）に渡される。上下限は不等式制約ではなく
`set_states_bounds`・`set_controls_bounds`・`set_time_final_bounds` で与える方が安定する。
等式で固定した端点に同じ不等式を重ねてはならない。

## 動画の見方

例題の動画は例題のPythonファイルの解を Matplotlib で描画したものである（[生成スクリプト](https://github.com/istellartech/OpenGoddard/tree/master/website/scripts)）。

| 表示 | 意味 |
| --- | --- |
| 灰色の点・目盛り | 一定時間ごとの位置。間隔が広いほど速い |
| 機体の図・炎 | 模式図。炎の長さは各段の最大推力に対する比 |
| 黒の縦線 | 現在時刻 |
| 背景色・縦の破線 | 区間（phase）とその境界 |
| 灰色の斜線 | エンジン停止 |
| 黒の破線 | 解析解 |

地球規模の図は高度方向を拡大しており、倍率を図中に示す。長い慣性飛行は早送りし、倍率を右上に示す。
