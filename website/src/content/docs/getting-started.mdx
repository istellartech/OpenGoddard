OpenGoddard は、連続時間の非線形最適制御問題を擬スペクトル法で非線形計画問題に変換し、SciPy で解く。
依存は NumPy・SciPy・Matplotlib のみである。

## インストール

Python 3.15 以上が必要である。

```sh
pip install OpenGoddard
```

例題を実行する場合は、リポジトリを取得して [uv](https://docs.astral.sh/uv/) で環境を構築する。

```sh
git clone https://github.com/istellartech/OpenGoddard.git
cd OpenGoddard
uv sync --locked
uv run python examples/01_minimum_energy_transfer/main.py
```

## 問題の記述

対象とする問題は次の形である。

$$
\min J = \Phi(x(t_f), t_f) + \int_{t_0}^{t_f} L(x, u, t)\, dt
\quad \text{s.t.}\quad \dot{x} = f(x, u, t),\ \ g = 0,\ \ h \ge 0
$$

[例題01](../examples/01-minimum-energy-transfer/)（$\dot{x}=u$、$x: 0 \to 2$、$J = T + \int u^2 dt$）での記述を示す。

```py
from OpenGoddard import DynamicsModel, Guess, LinearCallback, Problem

# 運動方程式 f：各ノードで独立に評価する
def pointwise_dynamics(x, u, time, obj, section, xp):
    return xp.stack((u[0],))

# 境界条件 g = 0：変数について線形なので LinearCallback を付ける
@LinearCallback
def equality(problem, target):
    state = problem.states_all_section(0)
    result = problem.condition()
    result.equal(state[0], 0)
    result.equal(state[-1], target)
    return result()

target = 2.0
problem = Problem([5, 8], [8], [1], [1], maxIterator=2)  # 時刻、ノード数、状態数、制御数
problem.set_unit_time(3)
problem.set_unit_states(0, 0, 2)
problem.set_states(0, 0, Guess.linear(problem.time[0], 0, target))
problem.set_controls(0, 0, Guess.constant(problem.time[0], target / 3))
problem.set_controls_bounds(0, 0, 0, 3)
problem.set_time_final_bounds(0, 5.1, 15)
problem.dynamics = [DynamicsModel(pointwise_dynamics)]
problem.equality = equality
problem.cost = LinearCallback(lambda p, obj: p.time_final(0) - p.time_start(0))  # Φ
problem.running_cost = lambda p, obj: p.controls_all_section(0) ** 2          # L

result = problem.solve(target, maxiter=100, ftol=1e-11)  # SciPy の OptimizeResult
```

`solve()` の第1引数はコールバックの `obj` に渡される。上下限は不等式制約ではなく
`set_states_bounds`・`set_controls_bounds`・`set_time_final_bounds` で与える方が安定する。
等式で固定した端点に同じ不等式を重ねてはならない。

## 動画の見方

例題の動画は `main.py` の解を Matplotlib で描画したものである（[生成スクリプト](https://github.com/istellartech/OpenGoddard/tree/master/website/scripts)）。

| 表示 | 意味 |
| --- | --- |
| 灰色の点・目盛り | 一定時間ごとの位置。間隔が広いほど速い |
| 機体の図・炎 | 模式図。炎の長さは各段の最大推力に対する比 |
| 黒の縦線 | 現在時刻 |
| 背景色・縦の破線 | 区間（phase）とその境界 |
| 灰色の斜線 | エンジン停止 |
| 黒の破線 | 解析解 |

地球規模の図は高度方向を拡大しており、倍率を図中に示す。長い慣性飛行は早送りし、倍率を右上に示す。
